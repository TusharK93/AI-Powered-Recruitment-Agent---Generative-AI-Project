# 🚀 AI-Powered Recruitment Agent Using Generative AI

## 📌 Project Overview

**AI-Powered Recruitment Agent** is an end-to-end **Generative AI** application that automates and enhances the recruitment process using **Large Language Models (LLMs)**, **LangChain**, **Python**, and **Streamlit**. The system acts as an intelligent recruitment assistant capable of analyzing resumes, matching candidates with job descriptions, answering recruitment-related queries, and providing AI-driven hiring insights.

Designed with a modular and production-ready architecture, this project demonstrates how Generative AI can streamline talent acquisition, reduce manual screening efforts, and improve hiring efficiency through intelligent automation.

---

## 🎯 Business Problem

Recruiters often spend significant time reviewing resumes, comparing candidate profiles with job requirements, and responding to repetitive hiring queries. Manual screening can be time-consuming, inconsistent, and inefficient, especially when handling large volumes of applications.

This project addresses these challenges by leveraging **Generative AI** to automate resume analysis, candidate evaluation, job matching, and recruitment assistance, enabling faster and more informed hiring decisions.

---

## 💡 Solution

The AI Recruitment Agent uses **Large Language Models (LLMs)** with **LangChain orchestration** to understand resumes and job descriptions, generate candidate evaluations, answer HR-related questions, and provide contextual hiring recommendations.

The complete pipeline includes:

* Resume Upload & Parsing
* Job Description Analysis
* Candidate–Job Matching
* AI-Powered Resume Evaluation
* Skill Gap Identification
* Interview Question Generation
* Candidate Ranking
* Conversational AI Chat Interface
* Prompt Engineering
* LLM Integration
* Streamlit Web Application Deployment
